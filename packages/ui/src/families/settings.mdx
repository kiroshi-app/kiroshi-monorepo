# Settings

The dialogs that configure a bot, a user, a space, a conversation or a plugin, plus the panels each of them holds. Every panel is a composition of **Forms** controls bound to one subject, which is what the sub-levels below name.

## Bot

- **BotSettingsDialog** — the dialog shell and its rail.
- **BotIdentityFields** — name, avatar and description.
- **DangerZone** — deletion and other irreversible actions.
- **EnvironmentPanel** — environment variables, written and never read back.
- **McpServerEditor** — one MCP server's configuration.
- **McpServerLaunch** — the launch command and its arguments.
- **McpServersPanel** — the server list.
- **MemoryPanel** — persisted memory entries.
- **RuntimeFields** — model, transport and runtime options.

## User

- **UserSettingsDialog** — the dialog shell and its rail.
- **SettingsScreen** — the same entries as a whole window, the settings menu in place of the conversations panel.
- **AppearanceFields** — theme and density.
- **LanguageFields** — interface language.
- **NotificationFields** — notification preferences.
- **YourDevices** — the devices signed in to the account, each removable in place.

## Space

- **SpaceSettingsDialog** — the dialog shell and its rail.
- **SettingsScreen** — the same entries as a whole window, the settings menu in place of the conversations panel.
- **SpaceFields** — name, tint and description.

## Conversation

- **ConversationSettingsDialog** — the dialog shell and its rail.
- **ParticipantsPanel** — the participants of an existing conversation.

## Plugins

- **HistoryChangePage** — one change of that history, pushed over the dialog.
- **HistoryPanel** — plugin run history.
- **McpSession** — the server list and the server editor as one composition.
- **SkillEditor** — one skill's definition.
- **SkillsPanel** — the skill list.
