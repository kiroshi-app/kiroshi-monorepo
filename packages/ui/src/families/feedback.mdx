# Feedback

What the system reports about itself: progress, status, notices and failures. Every component here is read-only and never conveys its meaning through colour alone.

## Components

- **ActivityIndicator** — the live "something is happening" mark.
- **AppBootScreen** — the surface shown while the app starts.
- **ConnectionStatus** — transport reachability at a glance.
- **ImportRow**: one companion, instruction file or skill found in ~/.claude, with its checkbox or import status.
- **ImportScreen**: what Kiroshi found in ~/.claude, the reader's pick, and how the import went.
- **Notice** — an inline informational, warning or error banner.
- **NewDeviceScreen** — what a computer shows while it waits to join an account.
- **OnboardingWelcomeScreen** — the three Welcome screens before a model provider is connected, with the step footer.
- **OnboardingConnectScreen** — connecting the model provider: a login found, sign in with Claude, a key, and their failures.
- **ProgressRing** — the same value closing as an arc.
- **SpaceAccessBanner** — why a joined space's thread can no longer be used as before.
- **Skeleton** — the registry placeholder box waiting content takes the shape of.
- **UpdateBadge** — the "a new version is available" marker.
