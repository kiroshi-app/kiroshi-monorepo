# Layout

Shells and regions that hand room to their slots and draw nothing themselves. They define where a screen's parts sit; the parts come from every other family.

## Components

- **AppHeader** — the top region and its slots.
- **ContentCard** — the frame a screen floats in on the shell surface.
- **RowAnatomy** — the media, name line and second line every row is built from; `SidebarListRow`, `ReportedRunRow` and `SearchResultRow` render it.
- **ScreenLayout**: the page frame every screen shares, a header slot, a content column (optionally centred) and a footer slot.
- **ThreadLayout** — transcript, composer and side context in one frame.
- **WorkspaceShell** — sidebar plus content, the outermost frame.
