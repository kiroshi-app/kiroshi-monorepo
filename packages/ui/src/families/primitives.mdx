# Primitives

Single-purpose building blocks with a variant API and no domain knowledge. Everything else in the system is assembled from them, so a change here reaches every family below.

## Components

- **Avatar** — the registry circle, sized from a closed set.
- **InitialsAvatar** — the reader's face, sized in pixels, falling back to initials.
- **Badge** — a short inline label with a tone.
- **Button** — the variant and size matrix every action goes through.
- **DeviceCard** — one device as every device surface names it, with its six-word fingerprint.
- **Item**: the registry list item, a root with media, content, title, description and actions parts.
- **TooltipButton** — the button whose name lives in a hover-and-focus label.
- **Accordion**: the registry stack of headed triggers, each opening its own panel.
- **FaqList**: question and answer items drawn as an accordion that keeps several answers open.
- **Disclosure** — an animated open/closed region that respects reduced motion.
- **Kbd** — the key cap a keyboard shortcut is written on.
- **Separator** — the registry one-pixel rule, on either axis.
- **SharedMark**: the slot that says which of two positions holds a companion's mark; it appears there outright.
- **TextShimmer** — a shimmering text placeholder for pending copy.
