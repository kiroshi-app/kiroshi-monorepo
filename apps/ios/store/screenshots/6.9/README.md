# App Store screenshots, 6.9-inch

Regenerate these with `bun run ios:screenshots`, which runs `apps/ios/scripts/store-screenshots.sh`: it builds the `StoreScreenshots` test plan and runs the `StoreScreenshots` UI test on the "Store iPhone 17 Pro Max" simulator (iOS 27, light appearance, status bar overridden to 9:41 with full battery, Wi-Fi and cellular), plus a throwaway signed-out twin for Sign in. The signed-in screens (Conversations, a Conversation, Missions, Settings) capture against a dev Space whose account is already signed in on "Store iPhone 17 Pro Max". If it has no session, the script opens Kiroshi there and asks you to sign in, then to run it again. `STORE_SPACE` and `STORE_CONVERSATION` pick the Space and the Conversation. The script writes `01-sign-in.png` through `05-settings.png` here, 1320 × 2868 each. The five PNGs aren't committed with this README: they come with a separate ticket once Steve is signed in on that simulator.
